# Known limitations — 1.0.0rc24

Current execution evidence is in ACCEPTANCE_RESULTS.json. Historical receipts are explicitly identified; an implemented feature is not a universal accuracy or compatibility guarantee.

- **Platform:** this candidate is tested on Ubuntu 22.04.5 WSL2 x86-64. Native Ubuntu 22.04/24.04 desktop installation and actual application-menu launch remain NOT_TESTED. CI definitions do not replace executed native desktop acceptance.
- **Human review:** genuine human workflow acceptance remains AWAITING_HUMAN_UAT. Scripted actions use automated_qa and never count as human approval. This candidate must remain a prerelease until the specified native/human acceptance is complete.
- **Real model evidence:** rc10 executed SAM2 automatic full-image jobs at 512 square and 640×384, point/negative/box prompts, local SAM3 point/box prompts and newly trained YOLO checkpoint reuse. The full-image jobs used an 8×8 grid and batch64, not the heavier 64×64/batch512 default. Other presets have geometry/API coverage, not a new complete real-model benchmark.
- **Training:** two earlier 3-epoch YOLO runs demonstrate training, cumulative snapshots and actual subsequent model loading. Tiny automated QA fixtures produced zero validation metrics and zero next-round proposals at the tested threshold; useful accuracy is not established. The rc23 tile-pipeline integration additionally ran one synthetic epoch and fresh-checkpoint inference; see docs/TILED_PIPELINE_RC23.md. No fit was run for the rc24 naming or GitHub packaging update. Real interrupted GPU training resume remains unmeasured.
- **SAM3:** still-image point/box assistance requires separately installed code and user-supplied local weights. Automatic generation, video, CPU inference and other checkpoint variants are unsupported/unvalidated. SAM3 material is not bundled or downloaded automatically.
- **Security:** only trusted checkpoints/configurations may be used. Provider subprocesses are not a sandbox. Patched Pillow, Hydra and packaging tools are pinned for new runtimes; existing runtimes are not silently updated. Torch-specific advisory applicability and remaining limits are recorded in docs/DEPENDENCY_SECURITY.md; do not present this release as vulnerability-free.
- **Storage/performance:** native backups intentionally preserve masks, provenance and persistent undo/redo. They can be much larger than compact training annotation exports. Full-image history snapshots can grow quickly. Prefer the native Linux filesystem for active projects, not a Windows-mounted auxiliary path. No universal large-project latency guarantee is made.
- **Geometry/exports:** exact native masks can include holes/disconnected components; YOLO polygons cannot always preserve them. Strict conversion blocks unsupported topology. Explicit approximation has a conversion report. Detection/VOC outputs are boxes, not detailed masks.
- **Recovery:** heavy boundary recovery is OFF by default and requires scoped explicit consent in automatic-mask annotation, training preparation, or the prediction Boundary check option. Changes are held for review; a failed/no-improvement attempt preserves original geometry. Recovery accuracy is unmeasured. Import, ordinary prompts, manual edits, merge, rounds and export never enable it automatically.
- **Scope:** 2-D still images and instance segmentation. TIFF/high-bit-depth/multipage imports cover only the tested subset. No general DICOM/GIS, video, 3-D or remote/team-server support. Prepared-input policy does not guarantee backend augmentation never truncates an object.
- **Restoration:** native backups retain annotations/history and generation provenance, not background job artifacts. Restored layers cannot resume source-project jobs. Stale recovery suggestions must be dismissed before training and cannot replace changed geometry.

License/author approval is recorded in LICENSE_REVIEW.md. No public upload has taken place. Old documentation under docs/UPDATE_RC* and the named historical JSON receipts describes those original candidates; it is not current test evidence.
