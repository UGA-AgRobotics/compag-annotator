# Following the annotation workflow

The **Next step** guide in Images, Annotate and Jobs explains what to do next. In the editor it reads the current saved annotations and any live SAM preview. It never assigns classes, accepts masks, confirms review, changes dataset roles or starts training automatically.

1. **Import images.** Choose files or a folder and explicitly add them to the project. Open an image or choose **Continue image review**.
2. **Create masks.** Automatic **Generate masks** saves proposals. When its job finishes, choose **Open annotation results**. SAM point/box assistance instead creates a preview: inspect it, then **Save SAM previews as drafts** (or save the single preview). Unsaved previews are lost when leaving the editor; request a fresh preview if needed.
3. **Label and review.** Choose **Open labeling & review**. This shows pending masks even if display filters had hidden them; it changes display only. Select objects, choose or create a class, then **Assign class**. Correct shapes if needed. Check each mask and use **Accept selected** or **Reject selected**. Class assignment alone is not acceptance.
4. **Confirm the image.** With no pending masks, inspect the full image for missed objects, then **Confirm image review…**. The existing confirmation dialog still requires explicit attestation. A truly empty image can be marked reviewed using **Mark reviewed**, after checking the entire image.
5. **Choose your next task.** **Review next image** opens the next unreviewed, available, non-excluded image. **Export annotations** opens the export form. **Prepare training (optional)** opens the existing readiness checks, including separate reviewed validation images. These buttons navigate; they do not export or train automatically.

Failed saves take priority over further guidance. Incomplete automatic layers remain identified as incomplete. Undo and redo update the guide from saved state. Job history describes the operation at that time; it does not claim that its proposals are still unreviewed today.

If **Mark reviewed** opens **Image review is not finished**, the saved masks still need explicit acceptance or rejection. This is not a lost annotation save. The dialog shows how many labeled and unassigned masks remain, including hidden masks. **Show remaining masks** reveals them and selects one; **Review next pending mask** selects another. For a correctly labeled mask, use **Accept selected** after inspecting it. For an unwanted mask, use **Reject selected**. Continue until the pending count reaches zero, then mark and confirm the full image review. The editor remains usable; it does not enter failed-save recovery for this particular incomplete-review condition. Genuine storage, network and revision errors retain their recovery controls.

All application guidance is English and uses the existing light/dark theme. Models, inference settings, training rules, review attestation and export formats are unchanged.

If training lacks an assigned validation or training role, **Choose image roles before training** shows current pool/train/validation counts and explains the next steps. **Set image roles** opens Images and focuses a labeled **Dataset role** dropdown. Keep at least one reviewed image with an accepted segmentation instance as train (or pool), and a different reviewed image as validation. Imported images default to pool; completed pool images count as training. **Mark reviewed** does not select validation. Role changes save automatically and preserve completed review. Return to Train and **Refresh readiness**. Existing validation images that still need review are handled by the existing review guidance; the application does not claim their roles are missing. No roles, review decisions or training settings are changed by the guide.
