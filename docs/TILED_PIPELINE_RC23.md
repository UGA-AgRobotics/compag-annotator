# 512px training, prediction and contextual boundary recovery

This is an incremental implementation over rc22, not a claim of reproducing the research pipeline or its accuracy.

The supplied manuscript's Section 2.4/Table S1 specify 512px crops, stride 512, edge anchoring and bottom-right-pixel padding. Section 2.11 specifies full-image box NMS at 0.5. Its canonical learner is SAM2/XGBoost with optional YOLO disabled; it does not prescribe this application's YOLO training hyperparameters. Here, the crop/coordinate policy is adapted to real YOLO segmentation training and prediction.

The preserved `Standard_Optimized` sources were read without modification. `recovery.py` supplies context sizes [512,1024,1536], margin 32, three YOLO-backed attempts/one SAM-only attempt; native predicted IoU ≥ .80 and stability ≥ .88; target/fragment coverage ≥ .90; fragment share ≥ .03; area ratio [.8,3]; neighbour coverage ≤ .10; alternative IoU ≥ .95 and area ratio ≤ 1.10. The universal app independently adapts these gates to its canonical RLE, model providers and transactional review history. It does not import research registries, AL-round orchestration, reference annotations, contextual-YOLO identity certificates, or experimental strip acceleration. This is not bitwise-equivalent replay of the legacy pipeline. The contextual candidate is generated by a real SAM point/box prompt; SAM2 and SAM3 interactive-head logits supply the quality fields. No YOLO class score substitutes for mask quality.

Defaults and compatibility:

- New UI jobs: tiles_512, input 512. Legacy API jobs without training_mode retain whole-image behavior. Resume uses the original frozen snapshot/settings, never today's tiling controls.
- Tile labels preserve original pixels until an explicit, reported lossy conversion is selected. Training exclusions do not edit annotation masks or annotation exports.
- Prediction maps crop masks to full-image coordinates, removes padding-only masks, then performs deterministic per-class box NMS. It does not union arbitrary overlaps.
- Boundary checking is explicit, scoped and bounded. It is OFF for normal generation, training and prediction. Reviewed neighbours are never auto-merged. All accepted geometry replacements need a separate review decision; undo/redo includes companions and decisions.
- Per-tile validation metrics are not a measured full-image accuracy result. Improving detection still requires representative labeled data and independent validation.

Run software tests with `pytest tests --ignore=tests/browser`, browser tests with `pytest tests/browser`, and JS tests with `node --experimental-default-type=module --test tests/js/*.test.js`. The optional `scripts/check_tiled_pipeline.py --help` describes the bounded real-provider test. It requires explicit --execute, an isolated output directory, local model paths and installed provider environments. It never activates the QA model or opens a live project.

Measured rc23 integration: one epoch on two separate synthetic QA originals (six crops per split), one verified optimizer update, newly saved checkpoint loaded in a fresh process, six-tile prediction at input 512, 15 proposals before/6 after NMS, and one real contextual SAM2 call producing a reviewable suggestion. Original mask preservation and explicit retain were checked. Human acceptance, natural-image accuracy gains and SAM3 with local weights are unmeasured for this change. SAM3 weights are never downloaded automatically.
