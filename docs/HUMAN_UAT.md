2. Import six full images through Images. Assign two to fixed validation and four to pool; keep related groups in one split. Confirm import dimensions/orientation and duplicates handling.

4. In Annotate, perform the automatic-mask and selection/merge checks below. Then inspect full images, pan/zoom, draw/edit boxes and polygons, paint/erase a mask, preserve a hole/component fixture, change a class, undo/redo and reopen saved work. Label any synthetic geometry fixture as synthetic.

Confirm zero heavy-recovery plans/model calls with OFF. Do not shrink the image or stop after one tile. 3. Inspect proposals outside the original viewport and near seams; retain accessible overlapping/nested alternatives. Cancel a separate small job or use a clearly labeled fixture, inspect partial coverage, resume unfinished tiles and verify no duplicate append. Repeated Start must not duplicate work. Create a new layer and exercise replace-unreviewed without overwriting accepted/edited/rejected/merged history.
4. After generation, create at least three arbitrary classes in the editor. Select one mask, then several via Shift/Ctrl-click and object-list controls, and assign classes. Check counts, Unicode names, rename and stable identities after reopening. Selection does not prompt or label; assignment does not merge/accept. Reach nested/overlapping masks under zoom/pan using exact hits and list/cycle controls. Test deliberate Paint class separately from SAM prompt and Edit geometry.
5. Merge same-image fragments across tiles; use explicitly labeled synthetic masks if real output has no suitable fragments. Preview and verify exact pixels, holes/components, area and box for adjacent, overlapping and disconnected cases. Resolve a class conflict explicitly; allow an unassigned result. Confirm parents become superseded, child remains draft and no inference/recovery is called. Cross-image, box-only and stale-version selections must be rejected without partial changes.
6. Refine separately with brush/polygon/SAM preview; create a missing object; reject, hide and delete single/multiple masks with the appropriate confirmation. Undo/redo, restart and native restore must preserve the correct active parent/child set and review state. A stale prompt or regenerated layer must not resurrect parents or rejected objects. After substantive edits, confirm completeness needs review again. Resolve non-target proposals deliberately; do not label a partial scene as background.
