Image import: choose files or a folder, check the selected count, click Add images to project, then View images. Subfolders are included by default. Use Remove on an image card to remove it from the active project while keeping its original file.

Multi-picture JPEG/MPO files import their primary picture at full resolution; original files are preserved. In Projects, Delete project permanently removes the selected project's folder and job outputs after exact-name confirmation. External originals and shared models are kept.

Training preparation: choose Dataset role in Images, then use Confirm review under each chosen image. Confirm pending labeled objects only after inspecting them, and explicitly confirm the whole-image review. Unassigned objects need a class or rejection; an empty image needs separate negative-image confirmation. Then use Continue to Train for fresh readiness. This does not start training or bypass geometry/model checks.

Train opens its settings while Data readiness checks mask geometry. Large masks may take time; the panel shows elapsed time and an indeterminate indicator. Training still waits for validation. Failed checks offer Retry data check without clearing settings.

Start with your full images

  1. In Projects, create a project. You can leave classes empty and define them after generating masks.
  2. In Images, import files or an approved folder. Copying images gives the simplest portable project.
  3. In Annotate, draw or correct shapes manually, or choose Generate masks / Segment everything with a ready SAM2 provider. No YOLO or predefined class is needed. Generated masks are proposals requiring review, not a guarantee of finding every object.
  4. Choose Whole image or source tiles: 256×256, 512×512, 1024×1024 or independent Custom width × height. Preview original dimensions, overlap and full grid before starting. New projects start at 512×512 with 25% overlap. This is source crop size, distinct from model resizing and training image size. Existing grids and accepted masks do not change.
  5. In Select, click masks or use the object list. Create a class in the editor and Assign class to the selection. Assignment preserves separate instances and does not accept them.
  6. Inspect and explicitly accept target objects. Resolve relevant drafts/unassigned proposals or dismiss non-target ones. Confirm completeness only after checking the whole image for missing or incorrect objects. Hiding masks is not review.
  7. Use Export for native backup or annotation exchange. Native history and COCO RLE retain exact masks; strict YOLO may block holes/disconnected parts. Inspect any explicit conversion-loss report.

SAM Assist review and display

Independent SAM prompts no longer have a fixed point-count limit. Points are processed sequentially with progress and cancellation. Time and preview memory grow with the number of points. Points can be placed directly on existing or hidden masks. No saved-mask scan or duplicate warning interrupts point placement. Explicit Refine one object remains available.

Label & accept SAM Assist drafts (N)… lets you choose selected drafts or all SAM Assist drafts in the current image, select an existing class and explicitly confirm that you inspected the masks. The batch keeps separate instances and supports persistent Undo/Redo. It does not complete full-image review.

Selection offers Color for all masks and individual display colors for selected masks, including masks generated earlier. Reset all mask colors restores class colors. These preferences stay in this browser for the project image and do not alter annotations or exports. Show mask fill controls saved fills. The separate overlap highlight has been removed.

Select, label and correct

Select, Paint class, SAM prompt and Edit geometry are separate modes. A selection click must not also change a label or create a SAM prompt. Shift/Ctrl-click toggles multi-selection in Select; object-list controls provide an alternative. Check the selection count and use Clear selection. For overlapping or nested masks, use the overlap-cycle control or object list to reach the smaller mask.

Scroll to zoom; hold Space and drag to pan. Hold the right mouse button and drag to pan, including while placing SAM points. Press Ctrl+D in the annotation editor to remove the last temporary SAM point. The shortcut is inactive in forms and dialogs. Repeat to remove earlier points; saved masks and box prompts stay unchanged. Preview again after changing prompts. Ctrl/⌘+Z undoes and Ctrl/⌘+Shift+Z redoes. Geometry tools add/erase pixels or edit polygons; use SAM prompts for a separate preview. Current on-screen shortcuts take precedence, especially when editing vertices. Names typed in a form must not trigger canvas tools.

Hide changes display only; Reject dismisses a proposal; Delete removes an instance from the active annotation/export/training set. Confirm bulk or approved-data deletion. Draw missed objects when necessary. Undo/redo and restart must preserve the right active objects and review state. Check the save state before leaving.

Merge fragments, then refine separately

Select at least two mask-capable objects from the same image, including different tiles, then preview Merge selected masks. It combines exactly their existing pixels, retaining holes and disconnected parts. It does not fill gaps, infer a class or call a model. Box-only objects need separate mask creation. Resolve conflicting classes explicitly, or choose unassigned.

Merge creates a new draft and supersedes its parents. Accept after review unless you explicitly choose a combined Merge and accept action. Undo restores parents; redo restores the merge. Use separate brush correction or Refine merged mask with SAM to change missing/excess pixels. Manual merge/edit/delete/export work without optional models. Accepted merged objects feed rounds/training once, without active parent duplicates.

Optional assistance and training

Models & AI installs optional runtimes or registers trusted local checkpoints. Downloads require selection and consent. SAM3 uses user-supplied local weights. SAM3 automatic generation is unavailable until a compatible adapter is implemented and tested; its separate point/box assistance is not automatic-generation proof. Choose SAM2 for automatic proposals. Positive/negative SAM clicks describe included/excluded pixels, not semantic classes.

Jobs shows completed/total tiles, proposal counts, warnings, timings and cancel. An interrupted run remains partial. Resume the same generation's unfinished tiles without duplicate append; a fresh run uses a new layer or explicitly replaces only a selected unreviewed layer. Do not overwrite accepted/edited masks or revive rejected/merged parents. Provider quality/stability/duplicate filters are generation work; they do not certify complete objects.

Rounds organizes eligible review-pool images. Train uses cumulative live accepted segmentation from explicitly completed images, with fixed validation and an explicit class map. New training defaults to 512×512 source crops, stride 512 and input size 512. Whole-image training remains selectable. Tile-trained models remember the matching prediction layout; old models require a new training job to learn at that scale. Tile validation metrics describe tiles. Inference maps masks to the full image and suppresses duplicate boxes per class at IoU 0.5. Activation of a trained model is an explicit choice. YOLO best.pt model names include the date, time to the minute, timezone and short model ID. New records show training completion; older records show saved/registration time. The activation dialog repeats the selected name.

New YOLO training jobs adapt batch accumulation to the available training images and check actual learnable-weight changes before registration. Jobs reports verified updates; validation metrics still determine prediction quality. Replace an old ineffective short run with a new job from the original base model. See short training update checks.

If Train asks you to choose image roles, use Set image roles. In Images, use the labeled Dataset role dropdown under each image: keep at least one reviewed image as train (or pool), and a separate reviewed image as validation. Pool is the import default and counts as training after review. Mark reviewed does not assign validation. Role changes save automatically and keep completed review. Return to Train and click Refresh readiness; other reported issues still need attention.

For masks rejected by strict YOLO geometry conversion, choose Exclude incompatible objects (N)… in Train. Select individual objects and explicitly confirm their treatment as background. Original annotations and exports are kept, and lossy conversion stays off. Review training exclusions… restores selected objects. These choices affect future training/validation snapshots for all supported YOLO segmenters; existing snapshots and resumed jobs retain their original data. Omitted objects become background and may affect quality or metrics. Exclude the whole image by dataset role if partial labeling is unsuitable. Images with all accepted objects excluded are omitted from the new dataset, not counted as negatives.

Explicit boundary-check contexts

Heavy boundary recovery is OFF by default. It is allowed only with explicit consent for a scoped job in training preparation, automatic-mask annotation, or Boundary check in YOLO prediction. In Generate masks, the advanced Check/repair tile-boundary masks after generation (slower) option starts unchecked. You may instead choose Run boundary check on these proposals… afterward for selected proposals or the current generated layer. Inspect scope and resource limits before confirming.

In Predict selected, choose an installed SAM model and a maximum number of seam objects (default 3, up to 20). Contextual recovery checks native mask quality, original-fragment coverage, area growth and neighbours. At most three 512/1024/1536 contexts are attempted per YOLO seed; SAM-only seeds use one. Matching unreviewed fragments can be merged only after confirmation. Original fragments are shown together for comparison, and Undo/Redo restores the whole decision. Unresolved and deferred objects remain editable.

Review old/new geometry before applying a proposed replacement. Failed/unresolved checks keep original editable masks. A physical photo edge is not an internal tile seam; whole-image data without internal crop seams may be not applicable. Each job needs consent; one context does not enable the other. Import/open, manual edits/labels/prompts/merge, ordinary prediction, round transitions and export never trigger recovery automatically. Basic geometry checks, cheap seam flags and upstream provider filters remain distinct from heavy contextual model calls.

Backups and recovery

Export a native backup before updating. Restore into a new location. Model weights are excluded by default. Use Jobs for failure/retry states and Help & Settings for storage and diagnostics. An interrupted job is not complete. Review diagnostics for personal information before sharing.
