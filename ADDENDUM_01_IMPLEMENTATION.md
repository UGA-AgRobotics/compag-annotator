## Integration contracts to verify

- `plan_tiles(image_width, image_height, config=None, *, image_sha256=None)` returns schema version, canonical image identity, normalized mode/preset/width/height, authoritative percent-or-pixel overlap, resolved overlaps/strides, deterministic tile IDs/boxes/valid boxes/padding, count and plan hash. Final origins align to the far edge; no external padding is required for a smaller valid crop. UI dimensions are width × height; arrays may be height × width. Invalid fields use `TilingError.fields`. Legacy `tile_boxes` stays compatible.
- `ModelManager.generate_proposals(model_id, image_path, *, crop_box=None, settings=None, device='cpu', progress=None, cancel=None)` dispatches the worker's real `generate_proposals` operation. Crop-local returned masks carry coverage, original/crop/encoder transforms, settings, genuine quality metadata, checkpoint identity and timings. The core maps exact geometry and persists each tile. SAM2 uses the pinned AMG; SAM3 automatic remains unavailable with a reason.
- `/generate` freezes `image_ids`, model, tiling, settings, device, explicit batch confirmation, new/replace-unreviewed layer choice, optional recovery scope/limit, expected revision and request key. Layer status records completed/total tiles and plan/model/settings identity. Partial work is never called full coverage. Project defaults only affect new jobs.
- `/selection` validates one image and live IDs/revision for assign, accept, assign_accept, reject or delete. `/merge/preview` exposes exact geometry/area/bbox, parent IDs/revisions, proposed class and conflict. `/merge` requires confirmation; class conflicts require a target or explicit null. A child remains draft unless an explicit combined accept was requested. All rows/history change atomically.
- `/boundary/annotation` authorizes an explicit selected-ID or generation-layer scope. The worker authenticates the actual job/context and grant; it cannot trust a client-supplied phase. Only `training_preparation` and `automatic_mask_annotation` are permitted. Review applies proposed geometry against current revisions. Default import/open/edit/label/prompt/merge/ordinary inference/round/export paths make zero heavy-recovery calls.

## Superseded restrictions reconciled

The original master's section 0 requirement 11, section 2 boundary module description, sections 3–4 class setup, section 5.4 tiling, section 7 workflow, section 8 phase policy, section 13 tests, section 14 work plan and section 16 boundary self-check are historical requirements with these narrow replacements:

1. Training-only recovery becomes **training preparation or automatic-mask annotation**, OFF by default, scoped per job, explicit consent and review before application. Tests forbidding all annotation-time recovery must be narrowed; tests forbidding unrelated/default triggers remain required.
2. An explicit manual same-image exact-mask merge is required. It does not enable Fast-Stitching, automatic union, geometric repair inside Merge, research reruns or inferred object identity.
3. Zero-class generation/editing is valid; class assignment and human review remain separate. Unassigned objects are not a background class or training target.
4. Source tile width/height/overlap are real crop settings. They are separate from encoder/YOLO `imgsz` and separately chosen training crops. Existing jobs/grids/masks/snapshots remain immutable.

The README EN/FA, user guide, training guide, model setup, quickstart, changelog, architecture, migration notes, limitations, human UAT guide, inline controls and offline help now use the two explicit recovery contexts and default OFF policy.
